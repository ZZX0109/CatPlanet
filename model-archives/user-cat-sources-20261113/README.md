# Original cat model source archives

These are the four user-supplied cat packs documented in `docs/USER-CAT-MODELS.md`, plus the existing GreyTabbyCat OBJ ZIP. They are source assets, not the CatPlanet authored models or a complete backup of all local modeling experiments.

## Contents and provenance

- `kitten-source.zip`: Kitten.glb and its original texture files.
- `persian-source.zip`: Persian.glb and its original texture files.
- `norwegian-forest-source.zip`: Norwegianforest.glb and its original texture files.
- `sphynx-source.zip`: Sphynx.blend and its original texture files.
- `JC0L219A2-GreyTabbyCat-obj.zip`: original, byte-preserved archive containing one GreyTabbyCat OBJ. Its download source is not independently verified. **The referenced MTL and textures are absent from this ZIP. It does not contain the separate Blender model, rig, or animations.**

The first four packs were downloaded using Baidu Netdisk according to the existing project record. They were repackaged from the original source/texture directories on 2026-11-13, excluding `.DS_Store`. No model or texture bytes were edited. See `manifest.json` for sizes and SHA-256 checksums.

## Verification and limitations

All ZIP CRC checks passed. Source-member hashes are recorded for the repackaged archives. Files were limited to model and texture files; local metadata files were excluded. Basic credential-pattern and image metadata-marker checks found no matches. This is not a guarantee against every form of embedded metadata. No Blender scripts were executed and no new runtime-quality or licensing acceptance test is claimed.
