## 一项重要的纠正：短毛不代表毛根稀疏

LeRoy 正常短毛猫对照组的肩胛间毛囊密度为 84.3±12.6 follicles/mm²，前臂外侧为 132.9±24.0。该小样本说明，不能仅根据腿上毛短，就把腿部做成稀毛区。组织切片中的毛囊数量、长出的毛干数量和网页中绘制的代表性毛束数量，也不是同一个指标。

因此，模型应分别控制**密度、毛长、粗细、曲率和出毛方向**。具体分区系数是解剖启发的建模参数，仍需画面验证。本轮没有取得猫全身毛囊的可直接使用的三维地图。

## 转换成网页建模的方法

- **按位置组织被毛。** 使用参考皮肤上的连续区域权重，区分口鼻、眼周、额头、脸颊、胸颈、躯干、腹部、四肢和尾巴，保留鼻镜、眼球和脚底的排毛保护。
- **局部毛囊组。** 多根代表性毛束在同一小片皮肤附近分布，并共享基本走向与部分长度特征。所有毛根仍绑定合法三角形，不把偏移点悬在皮肤外。网页预算不足以逐一重建真实毛囊，组内绘制数量是渲染取舍。
- **细绒、过渡毛、保护毛。** 将可见几何分为细短软的底绒、中间尺度的过渡毛、较少且较粗长的保护毛，分别造型。这里的三种渲染角色不等于三种独立毛囊组织学类别。
- **身体形变仍受支持。** 毛根和局部毛流沿用上一轮参考表面绑定；捏脸、转头及趴卧后重新贴合。毛量、毛长、撤销、外观 JSON 和完整静态导出的语义继续保留。

修改前基线、实际网页画面和验证数据放在 `artifacts/coat-anatomy/`；`before/` 为本轮开始前的冻结结果，源码副本在 `source-before/`。原始猫素材和 Blender 母模保留。

## 已落实的构造

`lib/cat-coat-anatomy.ts` 定义连续区域场和三类毛的造型，`lib/norwegian-fur.ts` 将这些结果用于真实毛根和曲线生成，`lib/cat-coat-profiles.ts` 保留短毛、长毛各自的长度范围。

1. **六根一组的代表性皮肤片。** 面积采样选取锚点，再按相对密度权重接受；附近成员落在同一三角形的合法重心坐标内，最大扩散尺度受限制。六根是当前预算下的采样选择，不能当作猫每个复合毛囊实际只有六根毛。根部颜色继续来自原始 UV。
2. **局部三类毛。** 普通躯干的代表性比例约为细绒 74%、过渡毛 20.5%、保护毛 5.5%，脸、耳和尾部平滑调整。三类相对宽度系数为 0.62 / 1 / 1.78，分别使用不同的长度、抬升和弯曲。原先大量相似的披毛由更细的层次过渡，保护毛保留少量较长、较直的轮廓。
3. **分开处理短与稀。** 口鼻、耳背、四肢末端缩短并贴伏，面部和腿部仍保留覆盖。腹部仅用温和的相对采样降权；这组系数是造型选择，不是从论文恢复的猫全身密度值。
4. **保护编辑和预览。** 分组和造型在参考表面上固定；预览降低细节时对全体毛根取打散后的前缀，保留全身覆盖及毛型混合。完整静态快照仍更新全部设定毛束，毛量为零仍隐藏对应新增区域毛发；独立胡须保留。

本轮毛束上限仍为头部 36,000、胸颈 24,000、身体 70,000。原三组毛量与毛长、v4 外观参数、三种脸型预设、原生闭眼和姿态接口均沿用。

## 研究补充：毛型、身体区域与第 09 轮预算调整

### 论文观察：不把初生／次生毛直接换算成三个渲染类别

Searle 与 Jude 的 1956 年研究 **The ‘rex’ type of coat in the domestic cat** 区分了四类普通短毛猫被毛：较粗直的护毛（guard）、远端弯曲增粗的芒毛（awn）、根侧较细卷而远端增粗的带芒底绒（awned down），以及细而卷曲的底绒（down）。普通猫的一个 254 根样本分别为 **4、15、45、190 根**。作者也指出部分毛型存在过渡，分类边界不是完全绝对的。[期刊记录](https://link.springer.com/article/10.1007/BF02982964)、[经期刊许可转载的原文，Hair Structure 与 Table 1](https://snugglebugs.dk/genetics.html)

该研究另选取每类 12 根完整发育毛轴测量长度，普通猫护毛、合并后的芒毛类、底绒均值分别约 **42.1、40.1、41.3 mm**，样本中差异不显著；作者认为护毛看起来更长，主要与更直、更立有关。这不能推广为所有猫各层等长，也说明“护毛一定是底绒三倍长”不是普遍的生物学结论。Ryder 的中侧腹季节性样本给出另一组外层／底绒长度，研究部位、个体和方法的边界均应保留。[原文 Table 2 与相邻讨论](https://snugglebugs.dk/genetics.html)、[Ryder 原始摘要](https://pubmed.ncbi.nlm.nih.gov/1025634/)

Baker 的 1974 年猫皮肤组织观察记录：背部次生毛与初生毛约 **10∶1**，脐部约 **24∶1**；背部毛囊组围绕较大初生毛的排列并不代表其他身体位置。它支持按生长位置调整局部组合，不能证明全身使用同一个复合毛囊模板，也不能把组织学的初生／次生数量严格映成我们的 down／awn／guard 三类比例。[原始扫描，期刊正文第 330 页](https://gwern.net/doc/cat/biology/1974-baker.pdf)、[出版记录](<https://doi.org/10.1016/S0007-1935(17)35835-9>)

### 品种标准：胸颈需要三个形态区域

CFA 挪威森林猫官方标准描述：稠密底绒由较长、顺滑的护毛覆盖，外层毛向体侧披下；胸围由**短颈圈、两侧鬓毛、正面胸鬃**三部分组成，后腿毛饱满，尾部蓬松。这是该品种的外观标准，不是猫全身毛囊方向或长度的定量测量。[CFA 官方标准，Coat 与 Tail](https://cfa.org/wp-content/uploads/2024/03/norwegian-forest-cat-standard.pdf)

因此，后续可将现有大范围混合的胸颈模板拆成上述三个区域，并让背侧外层顺皮披向体侧。具体三维向量、长度系数、区域边界和毛束宽度仍属美术拟合，需要正面、侧面及趴卧画面验证；不能将这些参数标成论文恢复的真实生长图。Noel 与 Hu 的研究以背毛测量为主，讨论背毛通常长于脸、腿和爪部，以及底绒对毛层整体形态的作用，可用于支持这种分区思路，但没有直接提供可使用的全身三维导向场。[PNAS 原文](https://www.pnas.org/doi/10.1073/pnas.1809544115)

### 第 09 轮：重新分配代表性毛型，不增加毛根

第 09 轮保持头部 36,000、胸颈 24,000、身体 70,000 的**总容量 130,000**，沿用同一组种植点与随机采样流，通过连续躯干、腹部和胸颈权重调整 down／awn／guard 的代表性渲染组合。普通躯干目标约为 **88%／9%／3%**；腹部进一步偏向细绒，胸颈保留更多外层；纯头部、四肢和尾部的原毛型配比不作该项调整，交界处连续混合。腹部最终比例还受毛型分配函数保留少量护毛的上限约束，不能只读区域公式就当作实际统计。

这些百分比是固定网页预算内的**代表性渲染权重**，不是逐根复现 10∶1 或 24∶1 的真实毛囊数量。六成员皮肤片可以表达期望比例，但不保证每片都恰有一根护毛；它也不是生物学上的六根毛囊单位。当前毛型缓存由短毛与长毛共用，因此**短毛和长毛都会随这次配比调整改变**，不能声称短毛画面保持不变。
