# 虎斑猫捏脸（本地）

旧版访问 http://localhost:3000/studio/base?legacy=1 。默认入口已升级到 [结构猫头造型室](./CAT-CREATOR.md)。沿用 `npm run dev`，无需登录、邮件服务或云资源。

状态：这是局部网格形变与数据流程原型，尚未达到用户最新要求的游戏式猫咪捏脸深度。实际结构猫头、独立五官与部位编辑的下一阶段验收见 [目标修正](./CAT-REALISM.md)。

## 如何使用

1. 拖动滑块调整脸部宽度、脸颊、口鼻、鼻子、眼睛区域和耳朵，共 8 项。50 是素材原形，两端为有限范围的自然比例调整。
2. 用“脸部近看”看五官，用“三分之四”和“侧面”检查轮廓。拖动猫咪旋转，滚轮或双指缩放；“观察工具”内有单击按钮和灰材质。
3. 每次拖动或键盘调整形成一步历史，最多保留 40 步。重置和导入也可以撤销。
4. 点击“保存外观”，刷新会恢复。保存位置是当前浏览器的 `localStorage`，键为 `miaoxing.tabby-face.v1`；清除站点数据会删除它。
5. “导出外观 JSON”下载小型参数备份，可在另一浏览器导入后保存。只接受此模板、版本及 0–100 参数；导入失败保留当前编辑和已有保存。
6. “导出 3D 模型（GLB）”下载带贴图、16 个形变目标和当前权重的静态模型，当前文件约 21.5 MB，可在 Blender 等支持 glTF 的工具中继续编辑。灰材质仅影响预览，导出始终使用原材质。

手机预览在滚动时保留在上方，滑块支持触摸；键盘可用 Tab 选择滑块、方向键微调，Home/End 跳至两端。预览区域支持左右键旋转、加减键缩放，所有视角也有按钮。

## 这次实际完成的内容

形变根据这份素材实际的眼鼻位置、头部朝向建立局部坐标，不按世界 X 轴直接缩放。每个参数对应正负两个原生相对形变目标；保留原网格 UV 与材质，身体、颈部以下和尾巴不参与脸部形变。初始化时生成目标，拖动时只更新权重，不重复加载模型。导出文件包含真实的顶点形变，JSON 只记录参数。

模型加载失败或 WebGL 不可用时，编辑记录仍在，可以重试或先下载 JSON。浏览器保存失败会提示导出备份，不清空当前编辑。

这是静态外观编辑，还不能替代完整的动画母模：虹膜、瞳孔和高光来自原贴图，没有独立眼球或角膜；不能眨眼、移动视线或改变毛色。原素材的拓扑和表面瑕疵仍存在，有限范围的比例变化也不能塑造所有猫种。本轮不支持照片识别、自动重建、骨架、走路、趴卧或纪念房间同步。

## 代码和验证

- `lib/tabby-face.ts`：版本校验、真实面部坐标、局部形变与资源恢复。
- `components/useFaceDesign.ts`：编辑历史、显式本机保存与失败保留。
- `components/TabbyFaceControls.tsx`：8 项滑块与文件操作。
- `components/CatBaseReview.tsx`：模型加载、相机、实时渲染和 GLB 导出。
- `tests/base-face.spec.ts`：画布变化、键盘/触摸、撤销重做、刷新恢复、非法文件保留、GLB 再加载与形变权重、手机竖横屏布局。

```sh
npm run typecheck
npm test -- tests/base-face.spec.ts
```

最终检查：桌面与浏览器模拟手机的 2 项流程覆盖真实画布变化和文件往返；另对 8 项低/高值的 256 个组合检查实际形变数组，未发现翻面或非有限坐标，身体位置/法线变化为零。图像与几何报告在 `artifacts/tabby-face-studio/`。

测试证明功能与数据往返，不能代替写实美术评审或真实手机性能测试，也不保证所有中间参数都没有局部瑕疵。素材许可与制作来源见 [免费母模记录](./CAT-ASSET-SELECTION.md)。开发对照入口 `?compare=1` 的橘猫只读，不提供导出。
