# 第一版验收记录

日期：2026-11-02。环境：本地 macOS、Next.js 16.4.4、Docker PostgreSQL 17、Mailpit、Chromium。自动化用例在 `tests/room.spec.ts`；测试截图输出到忽略提交的 `test-results/`。

## 已验证的本地能力

- 双入口、无需注册创建；名字和基础猫必填，照片选填。
- 两个独立骨骼模型的加载、切换、走路、休息与回应；目视检查橘白修长猫和银灰圆润猫的实际画面。
- 鼠标直接点猫、触摸模拟直接点猫、按钮点击与键盘 Space/Enter。
- 休息中的猫回应后仍然休息；连续触发不会延长/叠加回应。
- 减少动态效果下两种模型停止持续动画；对比实际画布像素确认回应发生。
- 纪念照片、性格、回忆随完整草稿保存；另一个独立浏览器会话重新验证邮箱后恢复。
- 错误验证码、过期验证码、一次性消费、五次错误限制、重发间隔。
- 断网发送失败保留输入；照片上传失败保留文件预览与资料，重试保存成功。
- 原始图片校验；私有照片只允许所属账号访问。不同账号读取、删除或引用照片均失败。
- 版本不一致拒绝覆盖；跨站 Origin 的写请求被拒绝；退出后私人接口返回未登录。
- 编辑/删除回忆后保存结果正确；删除照片和删除宠物均验证本地文件实际消失。
- 模型加载失败可重新加载；WebGL 不可用时仍保留资料编辑能力。
- 390×844 手机竖屏、844×390 横屏、1365px 桌面布局，无横向溢出。
- 类型检查、依赖漏洞检查、Docker 生产构建；容器首页和模型资源返回成功，镜像不包含 `.env.local` 或 `.data` 私人目录。

## 已知产品边界

- 每账号一只纪念宠物、一张当前纪念照片（同时用于头像和相框）；最多 50 段文字回忆。
- 小橘休息是程序侧卧，团团使用原生 sleep 动作；两者均为基础外形，不是照片生成模型。
- 走路为原地步行动画，当前不实现房间路径寻路。
- 回忆增删改后需要点击保存；照片和整只宠物的确认删除立即提交。
- 未保存草稿使用 IndexedDB，包含资料、照片、外观和未完成回忆。刷新后明确选择恢复或放弃；账号分别存储，退出登录或保存后清理对应草稿。草稿有效期 7 天，读取时清理；存储不可用时可继续在页面内存编辑。浏览器清理、强退或未完成写入仍可能丢失本机草稿。
- 本版已有固定规则生成的离线日记；没有聊天、AI 故事、多人社区或照片转 3D。
