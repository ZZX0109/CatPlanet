# 开发目标核对

核对日期：2026-11-04。保留原六项目标；“本地已验证”不代表正式上线完成。用户最新约束是先看本地、暂不接 AI。建模由另一个任务流继续负责。

| 原目标 | 当前证据与结果 | 未完成或适用边界 |
| --- | --- | --- |
| 1. 建立模型接入规范 | `MODEL-INTEGRATION.md` 约定坐标、尺寸、动作、外观和文件版本；两份不可变模型存档通过哈希校验 | 素材公开分发权限仍未核实；存档固定 GLB，运行时渲染代码仍共享 |
| 2. 打通外观保存与房间加载 | 导入造型室 JSON，账号存外观和模型版本；测试证明独立登录恢复、非法参数拒绝、旧客户端更新保留版本 | 当前以 JSON 导入衔接造型室和房间 |
| 3. 完善房间互动 | 两只基础猫支持走路、休息、轻触，镜头按钮、WebGL 与文件失败重试均有浏览器验证 | 基础猫走路为原地动画；定制猫暂为站姿与转身回应，新动作待建模侧完成后接入 |
| 4. 完善资料与保存体验 | 照片和回忆管理、账号保存、版本冲突、草稿恢复、账号隔离、失败重试均有测试；草稿包含未完成回忆和照片 | 草稿属于本机浏览器存储，有效期 7 天，清理或强退可能丢失 |
| 5. 部署与真实设备验收 | 已有部署配置；本地邮件、照片隔离及跨会话恢复通过；三种手机配置覆盖布局/触摸；新增本地备份恢复演练通过 | 正式邮件、COS、HTTPS、异机备份和真机性能未验收；按用户要求暂不部署，手机结果为 Chromium 模拟 |
| 6. 聊天与离线日记 | 规则日记已持久化，按时间补记，标为虚拟故事，与真实回忆隔离 | 用户明确暂不接 AI；聊天未实现，日记也不使用 AI |
