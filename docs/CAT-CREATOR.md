# 猫咪造型室：三类基础模板

本地访问 http://localhost:3000/studio/base ，沿用 `npm run dev`。当前按用户反馈默认使用完整程序被毛，保留挪威森林猫母模、真实捏脸、UV、材质及原生耳毛。无毛、短毛、长毛选项保留；“仅看原模型”可作对照。[最新完整被毛修复与验证](./CAT-PROCEDURAL-GROOM-REPAIR.md)覆盖了后续默认状态，下文与历史原素材记录不应混用。网页无需 Blender 常驻、账号或云服务，默认四脚落地、头部朝前，可切换闭眼、呼吸和趴卧。完整写实质量仍在制作。

## 操作顺序

1. 新建默认长毛母模、完整被毛；上方保留三类基础选择。切换保留脸部数值并采用对应毛发默认值。长短毛共用当前母模及不同毛发造型，无毛猫用独立斯芬克斯模型。首次进入是全身正面站姿，不自动播放原动画。“自然脸”保留原素材脸型。可通过“正面 / 三分之四 / 侧面 / 全身”切换视角。
2. 选择“头型 / 眼睛 / 鼻口 / 耳朵”，使用滑块调整。脸部共 14 项：圆润、楔形、头宽、头深、脸颊、下颌、口鼻凸度、口鼻宽度、鼻梁、眼睛大小、间距、倾角、耳朵大小与外张。
3. 点选真实三维表面选择部位；在“拖动塑形”模式下拖动，同时调整该部位的两项参数。按钮和滑块提供等价操作，双侧协调调整。
4. 使用“灰模”观察形体，“材质预览”观察原始毛色。“自然脸”重置脸部参数并保留当前毛发；“重置部位”只重置当前组。
5. “设为对照”记录比较快照，再切换“查看对照”。支持撤销/重做；对照时先返回编辑，再继续修改或导出。
6. 点击“保存外观”保存在当前浏览器；在“备份与导出”中导出 JSON，换浏览器时可导入恢复。GLB 导出包含当前形体、形变目标、贴图、骨架和当前毛发的几何。

聚焦三维预览后，左右键旋转、加减键缩放、Home 回正面；也可展开“旋转与缩放按钮”。滑块可用方向键、Home/End 操作。手机支持触摸选部位、滑块和双指缩放。预览按需绘制，不自动播放动作。

圆润、自然、楔形预设已拉开头宽、脸颊、下颌与口鼻的组合差异；从全身选择时自动拉近头部。已保存外观仍保留原数值，重新点击预设即可应用新版。[参数、实际对照与检查范围](./CAT-FACE-PRESETS.md)。

## 分区毛发

选择“毛发”页签，先选择“原素材被毛”或“附加毛层（实验）”。原素材模式不准备或显示全身程序毛与实体底绒壳，六个旧参数仍保留，但不显示实验滑块。

进入实验模式后，独立调整“头部毛量 / 头部毛长”“胸颈毛量 / 胸颈毛长”“身体毛量 / 身体毛长”。身体组覆盖躯干、四肢和尾巴。毛量为 0 时隐藏新增区域毛束，基础贴图、表面及独立三维胡须仍保留；头部毛量也控制实验耳内毛。毛长为 0 是该实验毛型的最小长度。

“单独看毛发”隐藏基础表面，只显示本轮三维毛束，方便核对覆盖和轮廓；“材质预览”恢复整体，“灰模”隐藏新增毛发以检查脸型。毛发支持撤销、部位重置、对照、本机保存和 JSON 恢复。

毛束由 `lib/norwegian-fur.ts` 在已加载的猫表面生成：按三角形面积、局部相对密度与重心坐标种植代表性毛根组，从原始 UV 取毛色，依据骨骼区域和部位组织毛流，避开眼球、鼻头和脚底。头部、胸颈与身体分为细绒、过渡毛和较少的保护毛，分别处理粗细、长度和弯曲，耳冠与眼周另控制长度；每根采用 4 段渐细曲面条带，具有实际三维弯曲及轮廓，随脸部形变重新贴合。[猫毛囊研究与实现范围](./CAT-COAT-ANATOMY.md)。

实验最大容量分别为 36,000、24,000、70,000 束；实验短毛的预设毛量为 85%，长毛为 80%。原素材模式的全身实验毛束容量与绘制量均为零。两种实验毛型具有不同的长度与曲线，但仍有造型问题，不能代表已经完成的写实短毛与长毛。毛量改变实际绘制数，毛长重算对应几何，脸部形变后毛根重新贴合。

实验全身毛束在网页中生成，基础 `.blend` 和网页 GLB 不自带这套运行时毛束；原素材自身的几何耳毛则已经保留，之前误清理的 342 簇原耳毛已恢复。导出的 GLB 带当前显示的毛发，导入 Blender 后是网格毛束；不是 Blender 原生 Hair Curves / 粒子毛发系统。含实验毛发的导出文件和显存占用会明显增大。实体手机性能尚需实机验收。

毛流方向、局部坐标与分缕的后续研究、实际实现和同视角检查见[毛流研究记录](./CAT-FUR-FLOW-RESEARCH.md)。

## 保存与旧版本

当前外观 JSON 使用 `schemaVersion: 4`、`templateId: cat-foundation-v1`，包含 `coatType` 和 `coatMode`；本机存储键为 `miaoxing.cat-creator.foundation.v1`。保存显示模式、14 项脸部和 6 项实验毛发参数，不自动上传或与纪念房间账号同步。旧 v3/v4 文件缺少 `coatMode` 时恢复为原素材显示，其余参数保持。

旧挪威森林猫 v3 存档会迁移为长毛类型，保留原来的脸型与毛发设置；旧记录原文不被覆盖。旧程序猫、虎斑猫和结构猫头的数据不被删除；旧 JSON 不能直接套在新母模上，导入时会提示错误并保留当前调整。旧的 `miaoxing.cat-creator.v2` 存档不被覆盖。模型加载或导出失败也保留当前输入，可以重试。

灰模只是观察材质，导出会恢复真实贴图。导出使用独立骨架副本，保留形变目标及当前权重。GLB 一律导出当前静态姿态：原素材模式包含原毛面和必要胡须，实验模式另外包含完整设定毛量，均不夹带自动播放的旧动画。原动画保留在基础制作文件中。网页可切换站立与趴卧、预览呼吸眨眼；暂未映射到纪念房间的走路/休息操作。

## Blender 制作文件

- 原始素材：`assets/source/user-animal-pack-2026-11-04/` 下的挪威森林猫与斯芬克斯文件。
- 可继续编辑的 Blender 副本：`assets/authored/norwegian-creator.blend`、`assets/authored/sphynx-creator.blend`。
- 网页资产：`public/models/creator/norwegian-cat.glb`（约 24.4 MB）与 `sphynx-cat.glb`（约 29.6 MB），贴图嵌入；本地接口传输 gzip 后分别约 16.8 MB、16.3 MB。
- 新母模的来源、哈希、目标和坐标：`public/models/creator/norwegian-manifest.json`。
- 制作脚本：`scripts/build-norwegian-creator.py`。

本轮不重新生成或体素重建猫头。制作脚本保持中性顶点和 UV，依据原骨骼、局部解剖坐标、眼球连通组件与区域权重添加形状目标。头宽等控制协调移动眼球与眼周，眼睛大小围绕眼球中心变化。范围有意保持适度，并不支持所有品种的无限变换。

Blender 中保留 17,625 个原始顶点、49 根骨骼和 53 个非 Basis 形状键（脸型、闭眼及联动修正）；GLB 因 UV/法线边界会产生少量顶点拆分。中性外观的全部形状权重为零。源文件的哈希在制作前后相同，发布 GLB 使用临时文件后原子替换，避免浏览器读取未写完的文件。

重建当前母模：

```sh
npm run build:cat
npm run build:cat:sphynx
# 可选：同时生成 Blender 中性/修改对照图
npm run build:cat -- --render
```

无毛猫命令使用项目内 Blender 3.6，可通过 `BLENDER36_BIN` 指定；原挪威森林猫命令默认使用 `.tools/Blender.app`；其他机器可通过 `BLENDER_BIN` 指定 Blender 可执行文件。原始素材需已在上方本地路径，脚本不会自动从网盘重新下载。`npm run build:cat:legacy` 保留旧结构猫头构建，旧产物不会覆盖当前的 `norwegian-cat.glb`。

用户提供素材的修改、商业分发和用户导出授权尚未核实；当前仅本地开发，不能从分享链接推断获得授权。制作脚本没有把该素材标为 CC0。原文件与本地制作文件不进入 Docker 镜像；当前网页 GLB 位于 public，在对外发布前需处理其分发权限。

## 验证与当前限制

```sh
npm run typecheck
npm test -- tests/cat-creator.spec.ts
npm run build
```

三模板本轮验证记录在 `artifacts/cat-coat-templates/`，中性脸实际网页图在 `artifacts/cat-foundation/`。分区被毛初版记录位于 `artifacts/norwegian-fur/`，站姿与原母模检查记录仍位于 `artifacts/norwegian-creator/`。网页截图与 GLB 回读报告在根目录；离线 Blender 的 8 张中性/修改对照图单独放在 `blender/`，避免混用。

关键验证检查真实画布差异、形变后的顶点、导出后重新加载的骨架/UV/贴图、鼠标旋转、手机模拟触摸选部位与滑块、新版保存恢复和旧存档隔离。手机横竖屏使用浏览器触摸模拟，不代表实体手机的性能验收。

当前已有覆盖头部、胸颈和身体的分区三维毛束，可调毛量与毛长；仍属于网页实时条带毛发，并非离线渲染的电影级毛发。眼睛光学、原胡须表现、毛流精度与参数极值的过渡仍有提升空间，不把功能测试视作达到 C 参考的美术验收。已加入闭眼与趴卧，纪念房间中的猫尚未替换。

早期结构猫头的精修文档保留为历史记录，其独立眼球、闭眼和旧毛发能力不能视作当前母模已经实现的功能。

## 代码阅读入口

1. `lib/cat-creator-design.ts`：参数、预设、版本和范围校验。
2. `lib/cat-creator-model.ts`：实际形变权重、头部范围、解剖部位点选与骨架导出。
3. `components/useCatCreatorDesign.ts`：历史、本机保存、导入与对照。
4. `components/CatCreatorScene.tsx`：相机、材质、点选和拖动。
5. `components/CatCreator.tsx`：界面、模型加载与失败重试、文件操作。
6. `lib/norwegian-fur.ts`：三组表面绑定毛根、毛流、数量/长度与静态导出。
7. `lib/cat-fur-flow.ts`：连续解剖毛流、参考种子相关造型和随三角形形变的方向运输。
8. `lib/cat-coat-anatomy.ts`：按皮肤位置的连续分区、三类代表性毛干的长度/粗细/曲率。
9. `lib/cat-groom-guides.ts`：规范姿态下的局部引导曲线、长毛披毛造型与表面坐标。
10. `lib/cat-fur-material.ts`、`lib/cat-fur-compositor.ts`：毛丝方向着色、细毛覆盖和多层透明合成。
11. `scripts/build-norwegian-creator.py`：Blender 母模、站姿制作与资产发布。

本轮研究、实际对照、检查数据与剩余问题见 [毛发生长结构与写实迭代](./CAT-FUR-REALISM.md)。
