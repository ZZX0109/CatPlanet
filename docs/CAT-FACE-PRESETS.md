# 三种脸型预设的区分

本地入口：<http://localhost:3000/studio/base>。刷新页面后，重新点选“圆润脸 / 自然脸 / 楔形脸”可应用新版预设；已经保存的外观仍按原来的具体数值恢复。

## 现在分别改变什么

| 预设 | 正面观察 | 侧面观察 |
| --- | --- | --- |
| 圆润脸 | 额头较宽、脸颊饱满、下颌较厚 | 口鼻较短，头部深度稍收 |
| 自然脸 | 当前底模的原始比例 | 当前底模的原始侧脸 |
| 楔形脸 | 额头与脸颊较窄，下颌收拢 | 头部和口鼻更修长 |

旧版圆润和楔形仅分别启用 `Head_round`、`Head_wedge`。这两个综合目标的幅度较小，例如圆润目标只含约半档头宽、部分脸颊和很少的口鼻变化。新版将已有的多个形变协调使用，拉开轮廓，同时保留眼睛、鼻梁和耳朵的中性精调值。

从“全身”视角选择预设会切到正面头部近景；已经使用正面、三分之四或侧面近景时，切换预设保留镜头，便于同尺度比较。按钮同时说明主要差别。之后可以继续调滑块。

## 预设数值

| 控制 | 圆润脸 | 自然脸 | 楔形脸 |
| --- | ---: | ---: | ---: |
| 圆润头型 | 100 | 0 | 0 |
| 楔形头型 | 0 | 0 | 100 |
| 头部宽度 | 75 | 50 | 25 |
| 头部深度 | 35 | 50 | 70 |
| 脸颊饱满度 | 80 | 50 | 25 |
| 下颌宽度 | 75 | 50 | 30 |
| 口鼻突出程度 | 30 | 50 | 80 |
| 口鼻宽度 | 60 | 50 | 40 |

其余脸部精调值为 50。切换脸型继续保留当前基础猫类型、六项毛发设置，支持撤销、重做和 JSON 保存恢复。外观格式仍为 v4，原存档不自动改写；旧版圆润脸存档也不会被悄悄加宽。

## 实际检查

`artifacts/face-preset-refinement/before/` 与 `after/` 各有 18 张实际网页画布截图：短毛与无毛两套底模，三种预设，分别使用正面、三分之四及侧面。短毛和长毛共用形体目标；长毛仍保留独立毛发设置。

`after-long/` 另有长毛版本的 9 张同样视角截图，检查被毛覆盖后仍能区分轮廓。三个采集记录均无页面错误且源码全程稳定，模型文件与原发布摘要一致。

只读原生检查脚本 `scripts/audit-face-presets.py` 对比旧预设和新版组合。固定同一组脸部顶点、排除眼球与耳尖后，圆润与楔形的采样带宽度比，挪威猫由 1.158 增至 1.416，斯芬克斯由 1.138 增至 1.367。这个指标只描述限定采样带，不能当作整个头宽或美术评分。两套文件共 10 个检查状态均为有限数值，开放眼状态零原生三角形翻面，闭眼未移动眼球。

审查也记录了现有挪威猫宽度/深度形变中的轻微眼球非刚性，最大约为眼球直径的 0.493%；本轮保留原目标，没有把它表述成完全刚性。浏览器另检查实际眼睑遮挡与画面。报告为 `verification/geometry-before-candidate.json`。

网页测试入口为 `tests/cat-presets.spec.ts`：直接测真实顶点的脸颊宽度、口鼻前突、原形恢复和眼睑遮挡；检查下半身固定采样保持不变、全部原生网格 UV 保持。手机浏览器模拟检查点按后画布变化、自动头部取景、近景镜头保持、保存恢复及 390/320 像素布局。

在浏览器的同一固定脸颊采样带上，新版两种预设的横宽差分别为旧版的 2.41 倍、2.18 倍，口鼻前突差分别为 2.92 倍、3.29 倍。这套测量使用实际网页姿态，与上面的 Blender 绑定空间采样带不同，不混用指标。自然脸的六张同视角截图修改前后像素一致。配对画面和计算范围见 `artifacts/face-preset-refinement/comparison.json`。

实现位置：`lib/cat-creator-design.ts` 定义组合参数，`components/CatCreator.tsx` 处理预设说明和近景取景。底模、原素材及上一轮毛流算法均保留。

最终联合回归 **18 项通过，0 失败、0 跳过、0 不稳定重试**，类型检查和生产构建通过；覆盖上一轮毛流、形变、动作、静态导出、压缩接口和原有保存恢复。完整结果为 `verification/regression.json`，最终摘要为 `verification/final-validation.json`。
