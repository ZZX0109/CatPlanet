# 毛量与毛长控制

> 当前 `/studio/base` 已改用挪威森林猫母模，详见 [当前造型室说明](./CAT-CREATOR.md)。本文保留此前结构猫头的制作与研究记录；其中旧毛发、闭眼等能力不代表当前母模已经具备。


本地造型室 `/studio/base` 新增「毛发」页签。

- 「猫毛数量」改变实际绘制的几何毛束，从 0 到 13,040 束（头部最多 12,000 束，眼睑最多 1,040 束），旁边显示当前数量。毛量为零时，皮肤的毛色贴图仍在。
- 「猫毛长度」控制头部毛束中心线长度，保留毛束宽度与毛根。眼周保持保护性短毛，胡须独立保留。滑块为相对长度，未作毫米标定。
- 「单独看毛发」显示立体毛束，便于检查数量、长度和轮廓。返回后继续观察完整猫头。
- 两项参数进入撤销/重做、本机保存、JSON 备份及对照；选择头型预设保留毛发设置。旧版只含14项脸型的 JSON 自动补入毛发默认值。
- GLB 导出保留当前实际毛量、毛长、捏脸和闭眼状态，去掉未显示的毛束；毛发检查视图不影响完整猫头导出。

`lib/cat-creator-fur.ts` 从稳定根部/中段/末端缩放几何中心线及全部原生形状差值，保留宽度。数量采用固定随机分布的前缀，调整不会随机重排毛根。长度变化时同步刷新 Three.js 缓存的原生形状纹理。

当前仍使用网页实时几何毛束近似，增加了体积与轮廓，但不等同于完整物理毛发渲染。高毛量会增加加载、显存和导出开销；实体手机性能仍需实测。

测试：`npm test -- tests/cat-fur.spec.ts tests/cat-creator.spec.ts`。实际截图位于 `artifacts/cat-fur/`。

本轮验证：毛发控制流程、现有捏脸/闭眼/触摸两项回归通过；实际导出检查选定10%毛量时头部索引为1200束，单独毛发检查模式下仍导出完整猫头；旧14项外观文件恢复成功。另用不同四边形三角划分检查毛根、毛束宽度保持与中心线缩放。类型检查与本地生产构建通过。
