# 猫咪工作室（本地）

访问 http://localhost:3000/studio ，也可以点击首页右上角“捏一只猫”。沿用 `npm run dev`，无需登录或云服务。

## 当前实现

- 独立的连续曲面短毛猫模型，由隐式曲面生成，使用共享顶点与平滑法线；不是把旧猫整体缩放。
- 22 根骨骼、7 个身体/脸部形状参数和 1 个趴卧修正目标，以及眼睛大小、间距、耳朵大小调整。共 10 个可调参数。
- 可调基础毛色、花纹颜色、虹膜颜色；纯色、虎斑、白胸白手套、三花；四套起始外观。
- 正面、侧面、面部近看、自由旋转与缩放、网格检查；站立、原地步行和趴卧动作。行走采用两节骨骼 IK，趴卧使用连续肢体曲线、腹部支撑和重新计算的法线；网页中动作平滑过渡。
- 40 步撤销、重做、恢复默认；本机保存与刷新恢复；校验后导入/导出 JSON 外观文件。
- GLB 导出包含网格、定向短毛、22 根骨骼、7 个可调形状目标、趴卧修正、虹膜与细毛法线贴图，以及三段动作。动作包含骨骼位置/旋转、趴卧修正权重和独立的眼睑闭合；可以导入 Blender 继续编辑。
- 遵循系统减少动态效果设置。手机支持旋转、缩放及相同参数编辑。

## 数据范围

外观保存到此浏览器的 `localStorage`，键为 `miaoxing.cat-studio.v1`。不会上传到服务器，不与账号或纪念宠物自动绑定。清除站点数据会删除本机保存，因此重要外观请下载 JSON。以后更换基础模型时需新增模板版本和迁移策略。

JSON 外观只描述参数；GLB 是可在其他软件打开的三维资产。模型、虹膜和细毛法线均由本地代码生成，不依赖外部贴图下载。旧 JSON 参数仍可读取，但显示的是新版基础形体，而不是冻结旧版模型。

## v2 精修（2026-11-03）

- 基础曲面采样从 82 提高至 160，按局部体积计算；缩短口鼻，分开鼻梁、双侧胡须垫和下巴，降低头部位置与耳根。
- 眼睛改为嵌入的杏仁形开口、带径向细纹的虹膜、竖瞳、湿润眼缘和可闭合眼睑。眼球不再通过整体压扁来模拟闭眼，移除了白色高光小球。
- 耳朵改为薄壁内凹耳廓、渐变耳内颜色和细小护毛；不再使用厚挤出的三角块。
- 32,000 根确定性、按表面积采样的两段渐细短毛，按脸颊、躯干、四肢、尾巴分区梳理，使用皮肤法线获得连续光照。微细法线贴图补充皮肤表面的毛流。
- 增加本地生成的室内环境反射和窗形光源，减少过强的均匀补光。
- 趴卧包括腹部支撑、收脚、放低尾巴与独立闭眼；专用修正保留折叠肢体截面，避免直接沿高度压成薄片。休息姿势的法线单独重建。
- 网格与基础毛发缓存复用，参数调整只生成当前设计副本；释放单只猫时清理网格、骨架和眼部纹理，共享细毛法线缓存保留。

## 写实质量：尚未达到目标

后续五轮精修改为共享顶点的 v3 基础网格，补充面部、眼缘、分区花纹、短毛细节和连续趴卧曲面；详情与实际对照见 [五轮精修记录](./CAT-REFINEMENT-5-ROUNDS.md)。当前短毛层使用 32,000 根渐细几何短毛与微细法线纹理，保持可绑定和 GLB 导出；它是网页近似，不能等同于 NeuralFur / AnimalLift 的高质量毛发重建。

本轮改善了原模型的玩具比例、浮起的眼球、粗糙毛发分布和趴卧折角，但仍是程序生成的短毛猫，尚未达到 C 图的照片级写实。仍需继续处理：

1. 进一步雕刻面部的不规则细节、眼睑与毛皮的过渡、鼻翼和嘴角；当前整体仍偏规则、对称。
2. 更密的底绒、真实毛束与毛色纹理；当前几何短毛和微法线无法替代完整毛发系统。
3. 组合参数极限下的局部穿插、趴卧的皮肤挤压和肌肉变化；修正不保证所有组合完全无穿插。
4. 更自然的步态和长期性能优化；手机测试为浏览器触摸模拟，不能替代真实设备性能验收。

下一次美术迭代应在 Blender 中精修一套中性短毛猫，再制作匹配的变形目标与关节修正。不能仅凭“滑块能动、文件能导出”就宣布写实建模已完成。

## 代码入口与验证

- `lib/cat-studio.ts`：外观参数、预设、导入校验。
- `lib/cat-builder.ts`：连续网格、形状变形、骨架权重、五官、毛发和动作。
- `lib/cat-eyes.ts`、`lib/cat-ears.ts`：带纹理的眼部与闭合眼睑、薄壁耳廓。
- `lib/cat-coat.ts`、`lib/cat-coat-normal.ts`：按毛流排列的短毛与可导出的细毛法线。
- `lib/cat-coat-pattern.ts`：连续毛色与分区花纹。
- `lib/cat-rest-surface.ts`：四肢趴卧时的连续曲线和脚掌形体。
- `lib/cat-muzzle.ts`：鼻部与渐细胡须。
- `components/CatStudioScene.tsx`：交互相机、灯光、渲染与资源释放。
- `components/CatStudio.tsx`：编辑、历史、本机保存与文件导入导出。
- `tests/studio.spec.ts`：验证实际画布变化、撤销、恢复、无效导入、贴图嵌入与浏览器解码、GLB 骨骼/变形/闭眼动作、半程动作混合、手机布局。

运行 `npm test -- tests/studio.spec.ts`。这组测试验证功能，写实质量需要单独目视评审；测试通过不代表美术质量通过。
