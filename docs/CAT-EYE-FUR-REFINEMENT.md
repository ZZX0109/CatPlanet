# 眼周与毛发续修

目标：减轻连续灰褐色“眼罩”，让实际眼睑、眉骨与脸颊的细毛连接自然。保持本地运行、14 项捏脸、独立眼球与闭眼，不增加付费或云端服务。对应制作阶段 `refinementRound: 6`。

## 原因与制作方式

此前下眼睑中央可见带宽约 0.0844，且整片眼周用近乎均匀的颜色补去旧假眼睛。头皮短毛又刻意避开眼睛，眼睑没有短毛，导致这圈表面特别明显。

本次外眼眶垂直半径由 0.155 改为 0.135，眼裂垂直半径由 0.098 改为 0.104，下睑开口系数由 0.72 改为 0.84。下睑中央带宽约 0.0476，比原来减少约 44%。保留共享外缘、球面保护与闭合线，眼球大小不因闭眼而变化。

毛色继续排除旧虹膜、照片高光和原鼻口图案；在同一排除区域内，用邻近许可毛色的连续延拓和短尺度毛纹补足细节。新制作逻辑放在 `scripts/creator-orbital-fur.py`，最终仍烘焙到模型自身 UV，网页没有相机前图片或假眼叠层。

首稿实际闭眼图发现长竖条，已否决。独立检查确认，窄的张眼眼睑闭合时大幅展开，原本短毛会被三角形拉长：上睑中性闭眼约 4.5 倍，联合参数达 5.1 倍。只证明毛根绑定精确不能说明毛发外观正确，必须检查闭眼的毛长与纹理密度。

## 文件与验证

修改前资产、原生 Blender 源和真实网页图保存在 `artifacts/eye-fur-refinement/00-before/`。几何隔离检查、纹理试稿与毛发绑定审计保存在同一目录的相应子目录中；试稿不能当成正式交付。

使用 `npm run build:cat` 构建当前阶段，`-- --round 5` 可复现上轮几何与皮毛路径。网页依旧访问 http://localhost:3000/studio/base 。

验证覆盖真实网页的正面、侧面、三分之四、近景与闭眼；导出的 GLB 需要重新加载，证明毛发与真实眼睑共同运动，并检查眼球保持、保存、撤销及手机触摸。原生毛发审计同时检查根部误差、毛长变化与表面夹角。

## 最终结果

已生成并发布本地正式模型：27 个组件，11 张嵌入且打包的图片，眼睑毛色/微法线由 512px 升至 1024px，头部毛色仍为 2048px。毛发为头部 2400 根、眼睑 1040 根，另有两侧各 7 根胡须。网页模型约 57.5 MB。

眼睑纹理以闭眼姿态展开和烘焙，消除闭眼后纹理被拉成梳齿的现象。新短毛按实际完整姿态计算表面方向，再生成原生形状及其交叉修正；不会把只有残差的 `Blink_Combo` 当成完整姿态重新算方向。中间状态仍使用原生形状的多线性插值。

正式 Blender 源的四个眼周毛发组件通过 8 组姿态检查：张眼、闭眼、圆脸、楔形大眼、眼大小/间距/倾角组合以及半闭眼。根部/顶点误差小于 `3e-7`，最大毛束轴线相对切面角约 26.2°，毛长比约 0.915–1.003，没有毛尖进入绑定表面。全部默认形状权重为 0。该检查属于有限姿态采样，不等同于完整写实毛流的验收。

制作脚本在同次构建中对毛色处理前后的原 20 个结构网格及全部形状坐标做精确 SHA 比较，全部保持不变。跨独立 Blender 构建的布尔/原语可能重排顶点或产生末位浮点差，不能仅用跨次顶点索引哈希断言材质制作污染几何；量化诊断保留在本轮产物目录。

固定网页相机、光照检查正面、近景、三分之四、侧面、闭眼和三种头型。修改后眼睑宽带及光滑灰褐色填充感减轻，细毛可以近看；仍有偏均匀的眼周色区，整体尚未达到 C 图的照片级质量。

最终 2 项浏览器流程、类型检查及本地 Docker 生产构建通过。实际导出再加载得到 27 个网格、88,536 个三角面；70 条眼部采样张眼均看见虹膜、闭眼均被真实眼睑遮挡，眼球形状保持。四个眼周毛发对象随真实闭眼目标移动；手机触摸、撤销、本机保存、导入与导出均已检查。网页、模型清单、几何报告、截图和生产镜像使用同一最终资产摘要。
