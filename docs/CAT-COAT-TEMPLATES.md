# 无毛、短毛、长毛基础模板

本地页面：<http://localhost:3000/studio/base>。现默认长毛母模、原素材被毛，不叠加全身程序毛。下表的分区毛束构造保留在“附加毛层（实验）”中；独立短毛和完整蓬松长毛仍待精修，原素材预览不能冒充两套已完成毛型。[当前默认行为与限制](./CAT-NATIVE-COAT.md)。

| 类型 | 实际基础 | 本轮构造 |
| --- | --- | --- |
| 无毛猫 | 用户提供的斯芬克斯 `.blend`，独立形体、UV、皮肤和骨架 | 保留皮肤、褶皱法线、耳廓和瘦长体型，增加脸部、闭眼及联动修正目标，提供 14 项捏脸控制；不生成被毛 |
| 短毛猫 | 原挪威森林猫网格与贴图 | 贴伏的密集短绒、较短的真实长度范围、较低的蓬松度和表面法线强度，保持躯干、四肢轮廓 |
| 长毛猫 | 与短毛共用解剖网格，独立被毛构造 | 底绒体积层、较长披毛、成束和重力下垂、胸颈围脖、后腿饰毛与沿骨骼梳理的蓬松尾毛 |

这不是三个独立品种的最终商业母模。短、长毛共用网格；同样的六项毛发数值会进入不同的毛流、长度和分层计算，不只是把同一种毛长滑块调大。无毛猫实际加载斯芬克斯文件，没有用原猫的毛量归零替代皮肤建模。

## 交互与保存

- 三类均默认正面站姿；可观察全身、正面、侧面和三分之四。
- 切换类型保留 14 项脸部数值，应用对应被毛默认值。不同底模的相同参数代表相对调整，不保证绝对外形相同；可用“自然脸”恢复当前底模的原始脸型。
- 实验模式下，短、长毛各支持头部、胸颈、身体的毛量和毛长。原素材模式和无毛猫不显示这些实验滑块，旧参数仍保留。
- 脸型预设保留当前被毛类型和毛发数值；类型切换、脸型、毛发修改均支持撤销、对照、保存和 JSON 备份。
- 长毛的底绒体积层使用实际表面 UV 和材质，在眼睛、头脸、足部与开放边界处避让或渐变贴回皮肤。“单独看毛发”隐藏底绒代理，只显示实际毛束。
- 各区域毛量为零会移除对应底绒代理面与毛束；三组均为零时，两者都不导出。
- 切换底模加载失败会保留当前捏脸参数，点击重试继续。

外观文件使用 `schemaVersion: 4`、`templateId: cat-foundation-v1`，包含 `coatType` 和 `coatMode`。存储键为 `miaoxing.cat-creator.foundation.v1`。旧 v3/v4 文件可导入，保留脸型、类型和毛发数值，默认显示原素材；旧 v3 沿用长毛类型。旧存储原文不会自动改写，早期结构猫 v2 不直接套用。

## 制作文件

- 无毛 Blender 副本：`assets/authored/sphynx-creator.blend`。
- 短、长毛共用的解剖 Blender 副本：`assets/authored/norwegian-creator.blend`。
- 网页原始基础文件：`public/models/creator/sphynx-cat.glb` 和 `norwegian-cat.glb`，分别约 29.6 MB、24.4 MB；压缩传输约 16.3 MB、16.8 MB。
- 皮毛类型配置：`lib/cat-coat-profiles.ts`。
- 实时被毛、底绒体积、表面绑定与导出：`lib/norwegian-fur.ts`。
- 新增无毛制作脚本：`scripts/build-sphynx-creator.py`；原始下载文件不覆盖。

重建基础网格：

```sh
npm run build:cat
npm run build:cat:sphynx
# 各命令附加 -- --render 可生成离线 Blender 检查图
```

无毛源文件来自旧版 Blender，使用已准备的 Blender 3.6。`BLENDER36_BIN` 可指定其可执行文件；挪威森林猫仍用 `BLENDER_BIN` / 项目内 Blender 4.5。网页毛束和长毛底绒在运行时生成，不是基础 `.blend` 中的原生 Hair Curves。导出是当前静态姿态与网格毛发；网页中的呼吸、趴卧不自动变成导出文件内的动画片段。

## 已检查与仍需优化

检查实际网页和导出后重新加载的三维数据：三类切换、无毛脸部顶点变化、毛流类型对实际长度的影响、底绒 UV/材质、毛量归零清理、旧文件迁移、保存恢复、失败重试、手机横竖屏操作。记录在 `artifacts/cat-coat-templates/`；中性脸的网页图在 `artifacts/cat-foundation/`；无毛文件的骨架、四足落地与 Blender 重新打开检查在 `artifacts/sphynx-creator/`。

建议下一步按以下顺序制作：

1. **眼球、眼睑、泪线。** 统一两种底模的眼睛光学与接触关系，解决漂浮、高光僵硬和眼周贴合问题。
2. **体型控制。** 添加胸腹胖瘦、躯干长度、腿长、肩高和尾巴比例；分别验收裸露皮肤轮廓与长毛覆盖后的轮廓。
3. **被毛美术。** 精修长毛边缘的颗粒、分缕、毛色边界与头颈过渡；为无毛猫增加皮肤色与褶皱强度控制。
4. **动作与毛发绑定。** 先完成站立到趴卧，再验证毛根、皮肤褶皱和长毛在动作中不穿插。

本轮是三类可编辑基础的第一版，仍未达到 C 参考的离线写实质量；实体手机性能和全部极端参数组合仍需实测。
